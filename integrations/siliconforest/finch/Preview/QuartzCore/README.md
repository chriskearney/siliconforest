# QuartzCore additions

Constants, private layer types, contents properties, and spring animation
parameters used by SwiftUI. This is the quartz-filter v2 set. It
supersedes the earlier quartz-filter sources.

`under-stub.m` is a link-time stand-in for the system QuartzCore
superclasses. `constant-checks.inc` lists the constant values the probe
checks.

Build outputs and the pristine QuartzCore image are not included.
