# Linux 7.2.11 upgrade plan

The owner authorizes overnight implementation, review, installation and necessary
reboots on the M1 Air J313 (OS firmware 13.5) and M3 Pro J516S (14.7). Recovery
and the earlier stage-1 branding migration are deferred until the owner returns.
This document records planned checks, not a passed qualification.

The stable target verified on kernel.org is 7.2.11 (15 October 2026). Ryan Murray's
omacom/linux-aurora PR139 at a9712ec4665edfaca5f9f39463f995b90f55daf3
provides a 7.2.10 integration reference. Its compile-only M3 GPU backend and
deferred display changes are insufficient for our machines: preserve the working
SiliconForest native GPU ABI and display fixes from 54add20fd52e, adapting them
to 7.2 rather than dropping them. Preserve the normal M1 driver and device-tree
paths, corrected C/Rust layout generation, SEP durability fixes and default-off
XART guard, audio, thermal and brightness behavior. Review conflicts explicitly.

Keep Mesa 7515336b3dfbe8943b555ffec9817b9ed64379a8 and m1n1
aca1258c2d7daad7db7079d4f89bb8217659f7ac fixed. Keep the installed local branding
package and boot configuration; a rebuilt UKI must retain the selected theme and
stamp its new kernel release. No stage-1, OS firmware, U-Boot, base OS upgrade,
suspend test, historical lab-reference rewrite or new branding rollout is in scope.

Claude owns kernel integration and source gates. Grok independently reviews the
upstream integration and the frozen result; an additional reviewer inventories
our existing contracts. Codex owns control changes, builds, signing and hardware
rollout. Nobody changes another worker's checkout. Preserve author attribution,
licenses and exact public provenance; no private source publication.

1. Capture current installed identities, hardware GL/Vulkan readback, compositor,
   display modes and errors; preserve all boot files, recovery archives and package
   rollback inputs. Preserve Connor's fence on the Air. Check idle sessions before
   any reboot. Keep the existing installed default as the one-shot fallback.
2. Run meaningful source/API regression tests and both production profiles:
   native-GPU J516S and normal J313. Require each existing render/compute UAPI:
   native 384/136 and normal 448/200, both with alignment 8. Require generated
   layout assertions, Image/modules and DTBs.
   Review config changes and every substantive merge resolution. Fix findings.
3. Use lab one-shot staging before persistent installation when admission and
   space permit. Use each Mac's current command line; do not substitute the older
   historical lab bring-up command line. Do not change frozen known-good records.
   A watchdog is available; no remote hard reset is currently available. Stop
   repeated boot attempts if a Mac requires physical intervention.
4. Build signed single-board candidates from the exact frozen source and reused
   Mesa/m1n1 packages. Validate signatures, hashes, dependencies, space and cached
   rollback packages before using the matched installer. Preserve every existing
   recovery entry and loader backup. Only losslessly archive verified redundant
   per-transaction ESP copies, retaining restore paths and independent root copies.
5. Verify an actual default boot: exact kernel, packages, Image, DTB, stage 2 and
   U-Boot; compositor-owned Mesa; hardware GL/Vulkan pixels; desktop and currently
   attached displays; brightness with restoration; Quake demo1 at the reference
   settings; no new GPU/display errors. Record the Air's existing brightness
   readback offset separately. Repeat after coordinated rollback and reinstall.
6. Publish new immutable component and matched board/firmware releases only after
   the evidence supports them. Test the versioned public one-liner and default
   boots on both Macs, then promote and verify the canonical latest bootstrap.
   No claim is made for absent docks, HDMI equipment, suspend or other models.

If an unsafe boot or graphics regression cannot be resolved, restore the verified
working stack and report the concrete blocker rather than leave a broken default.
